# ScribeDictation

Офлайн-диктовка для **Windows**: говорите в микрофон — русский текст печатается в активное поле (браузер, редактор, мессенджер, Cursor). Распознавание **на вашем ПК** (модель GigaAM), без отправки аудио в облако.

## Требования

| | |
|---|---|
| ОС | Windows 10 или 11, 64-bit |
| Микрофон | Доступ в «Параметры → Конфиденциальность → Микрофон» |
| Место на диске | ~4 ГБ после установки (модели уже внутри установщика) |
| Интернет | Только для **скачивания** установщика; для работы диктовки не нужен |

## Установка

1. Скачайте `ScribeDictationSetup.exe`.
2. Запустите файл двойным щелчком.
3. Следуйте шагам мастера установки.
4. На рабочем столе появится ярлык **ScribeDictation**. При первом запуске — подсказка по горячим клавишам.

**Автозапуск с Windows** — опционально, в настройках программы (иконка микрофона в трее → Настройки).

## Windows SmartScreen

Установщик может быть без платной подписи кода. Windows покажет синее окно «Неизвестный издатель»:

1. Нажмите **«Подробнее»** (или «More info»).
2. Выберите **«Выполнить в любом случае»** (Run anyway).

Это стандартное поведение для неподписанных exe; файл берите только с официального репозитория Releases выше.

## Как пользоваться (кратко)

1. Кликните в поле, куда нужен текст.
2. **Ctrl+Shift+D** или клик по плавающему микрофону — начало записи.
3. Говорите; текст появляется по мере речи.
4. Стоп: повторный клик / Enter / пауза (настраивается).

Горячие клавиши и микрофон меняются в настройках (ПКМ по иконке в трее).
